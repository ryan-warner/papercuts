commands

commanduse
papercuts add "<observation>"Record a concise description of avoidable friction. Use --stdin for piped input.
papercuts listList open entries for the current project.
papercuts show <id>Show one entry and its recorded project context.
papercuts resolve <id...>Mark one or more entries as resolved.
papercuts reopen <id...>Return resolved entries to the open list.
papercuts reviewInteractively review open entries and resolve selected items.
papercuts fixGenerate an agent-ready maintenance prompt from open entries.
papercuts statsShow totals, the oldest open entry, and average resolution time.
papercuts projectsList every project with recorded entries and its totals.
papercuts doctorShow the detected repository, worktree, working directory, and database path.

full reference: command guide

for agents

Because papercuts applies across projects, put its instructions in your global agent guidance:

agents — sh
$ papercuts agent-instructions >> "$HOME/.codex/AGENTS.md"
$ papercuts agent-instructions >> "$HOME/.claude/CLAUDE.md"

Then agents record papercuts as they work, and papercuts fix turns the backlog into a maintenance prompt.
